## Projects
*All school projects for now — personal projects coming soon*

**[Holidaze](https://tmh-holidaze.netlify.app/)** — Accommodation booking app built with React, TypeScript, and Tailwind CSS, using the Noroff API.  
Final exam project. The main challenge was handling authentication state and adapting the application to different user types: guests, authenticated users, and venue managers.

**[HelTech](https://heltech.netlify.app/)** — E-commerce application built with React, TypeScript, and Redux, using the Noroff API. Developed with [HelChris](https://github.com/HelChris), giving me practical experience collaborating with Git. Managing cart and checkout state across pages was the main challenge.

**[BidRally](https://torehirth.github.io/Bid-Rally/)** — Auction platform built with Vite, Tailwind CSS, and vanilla JavaScript using the Noroff API, with JWT authentication. Handling bid state and authentication without a framework was the main challenge — and it was also my first project writing automated tests with Vitest and Playwright.
